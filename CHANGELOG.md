# Changelog

## 0.1.0-alpha.2 — 2026-10-11

- Declare the verified OpenClaw build version required by the ClawHub external-plugin contract.
- Rendering code is unchanged from alpha.1.

## 0.1.0-alpha.1 — 2026-10-11

- First public math-only adaptation of OpenClaw Dashboard Extras v0.3.2.
- Local KaTeX-to-MathML rendering inside the host-owned native transcript.
- Inline and display TeX, conservative price/code handling, bounded rendering and sanitized output.
- No file-action handlers, backend tools, CDN, bundled fonts, or core patches.
- Tested with OpenClaw 2026.9.9; other host versions remain unverified.
- Includes source attribution, complete bundled dependency licenses and a public example.
