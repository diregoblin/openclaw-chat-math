## Inline math

The identity \(e^{i\pi}+1=0\) sits inside ordinary text. Prices $5 to $10 stay readable, and code `$x^2$` stays code.

## Display math

\[
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
\]
